# İnci Avı

Tarayıcıda çalışan, okyanus temalı bir kaçış / toplama oyunu.

## Nasıl oynanır

1. `index.html` dosyasını tarayıcıda aç.
2. **Oyuna Başla** düğmesine tıkla.
3. Balığı hareket ettir, incileri topla, denizanası ve kayalardan uzak dur.

### Kontroller

| Platform | Kontrol |
| --- | --- |
| Klavye | `WASD` veya ok tuşları |
| Fare / dokunmatik | Basılı tutup sürükle |
| Başlat | Enter, Space veya düğme |

Her inci **+1 skor**. 3 canın var; tehlikeye çarparsan can kaybedersin. En yüksek skor tarayıcıda saklanır.

## Dosyalar

- `index.html` — sayfa iskeleti
- `styles.css` — arayüz ve menü
- `game.js` — oyun motoru (canvas)

Kurulum gerekmez; doğrudan açıp oynayabilirsin.
